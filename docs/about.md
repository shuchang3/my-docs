
# 关于本项目

## 1. 项目介绍

本项目是一个基于 MkDocs 的个人技术文档网站。

通过 Markdown 编写网页内容，使用 MkDocs 将文档转换为静态网站，再通过 GitHub Pages 发布到互联网。

## 2. 项目目标

本项目主要有以下几个目标：

- 学习 Markdown 文档编写。
- 掌握 MkDocs 的基本使用方法。
- 了解 GitHub 仓库的基本操作。
- 学习 GitHub Actions 自动化部署。
- 实现修改文档后网站自动更新。

## 3. 使用的技术

| 技术工具 | 主要作用 |
|---|---|
| Markdown | 编写网站内容 |
| Python | 提供运行环境 |
| MkDocs | 构建静态文档网站 |
| Material | 美化网站界面 |
| Git | 管理项目文件 |
| GitHub | 托管项目代码 |
| GitHub Actions | 自动构建和部署 |
| GitHub Pages | 发布网站 |

## 4. 项目实现原理

首先，在 docs 文件夹中编写 Markdown 文件。

然后，MkDocs 读取这些文件，根据 mkdocs.yml 中的配置生成网站。

最后，通过 GitHub Actions 自动构建网站，并将生成的文件发布到 GitHub Pages。
